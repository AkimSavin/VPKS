Руководство по использованию программы

Последовательность действий для создания вашей DIY-инструкции:

Шаг 1. Новый крафт

Нажмите «Новый крафт», введите название проекта, выберите категорию и загрузите фото обложки.

Шаг 2. Ресурсы

В открывшейся карточке укажите необходимые Материалы (с количеством), Инструменты и Теги.

Шаг 3. Этапы сборки

Добавьте пошаговые Этапы с фотографиями процесса, чтобы ничего не забыть во время работы.

Шаг 4. Режим чтения

Запустите «Пошаговый режим чтения» и нажимайте «Сделано» на каждом шаге!
